# Answer sound source

`pika-source.mp3` is the high-quality preview of **“weird pikaCHU!”** by
Freesound user **chestnutjam**.

- Source: https://freesound.org/people/chestnutjam/sounds/399286/
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Original description: a child-created imitation; it was not sampled from a
  Pokémon episode or game.

The app plays a short opening segment. For an incorrect answer, playback is
slowed and pitched down in the browser to create a sad variation.

# Google TV 家庭學習遊戲

這是一個以 Google TV 為主要使用情境的家庭學習遊戲平台。第一個遊戲是「九九乘法」，後續可以擴充加減法、英文單字、國字或其他學習遊戲。

## 產品目標

- 適合在電視上全螢幕使用。
- 字體大、畫面簡潔、對比清楚。
- 可用 Google TV 遙控器方向鍵與確認鍵操作。
- 不依賴後端資料庫，第一版使用瀏覽器 Local Storage 儲存資料。
- 專案架構保留未來新增其他小遊戲的空間。
- 未來可進一步改造成 PWA，讓 Google TV 上的使用體驗更接近 App。

## 首頁

首頁採用「家庭學習平台」概念，而不是只有單一九九乘法頁面。

目前顯示：

- 九九乘法
- 加減法（敬請期待）
- 英文單字（敬請期待）
- 國字練習（敬請期待）

## 玩家功能

家中可建立多位玩家。

- 第一次使用可新增玩家名稱。
- 曾經使用過的玩家會保留在玩家清單中。
- 下次可直接用遙控器選擇玩家，不需要重新輸入。
- 每位玩家分開記錄：
  - 歷史最高分
  - 最近一次成績
  - 遊玩次數
  - 各乘法題目的答對／答錯次數
- 可清除單一玩家紀錄。
- 可刪除玩家。

資料儲存在 Google TV 瀏覽器的 Local Storage 中。只要沒有清除瀏覽器資料，關閉網頁、重新開啟或重新開機後仍會保留。

## 九九乘法遊戲

### 題目範圍

- 1 × 1 到 9 × 9。
- 題目順序隨機。
- 系統可根據玩家過去答錯的題目增加再次出現的機率。

### 遊戲模式

第一版提供兩種模式：

1. 四選一
   - 顯示題目，例如 `6 × 7 = ?`
   - 下方顯示四個大型答案按鈕。
   - 干擾答案會盡量接近正確答案，不使用過度離譜的答案。

2. 數字輸入（進階）
   - 顯示題目，例如 `6 × 7 = ?`
   - 下方提供 0–9 的大型數字鍵。
   - 玩家自行輸入完整答案。

### 時間模式

每局固定為 **60 秒**。遊戲畫面會顯示剩餘秒數與倒數進度條。

### 答題流程

1. 顯示題目。
2. 玩家用遙控器選擇答案。
3. 確認後立即顯示：
   - 答對或答錯
   - 正確答案
4. 畫面停留，不自動跳題。
5. 玩家按確認鍵後進入下一題。

這樣可以讓孩子有時間重新看一次正確答案，加深記憶。

### 計分

第一版採簡單計分：

- 答對：+10 分
- 答錯：不扣分

每局結束顯示：

- 本輪分數
- 答對題數
- 答錯題數
- 正確率
- 歷史最高分

## Google TV 遙控器操作

主要支援：

- 上、下、左、右：移動焦點
- OK / Enter：確認
- Back / Escape：返回上一層或離開設定

網頁會使用明確的 focus 樣式，讓目前選中的按鈕在電視上非常清楚。

## 視覺設計

- 橫向電視畫面優先。
- 全螢幕配置。
- 大字體。
- 大型按鈕。
- 高對比。
- 避免細小文字與複雜選單。
- 動畫保持簡單，不干擾學習。

## 音效

第一版保留簡單答題音效介面：

- 答對：輕快提示音。
- 答錯：溫和提示音。

預設可關閉，避免電視音量過大時造成干擾。

## 技術架構

第一版使用純前端：

- HTML
- CSS
- Vanilla JavaScript
- Local Storage

不需要伺服器與資料庫。

建議專案結構：

```text
/
├─ index.html
├─ styles.css
├─ app.js
└─ README.md
```

第一版刻意維持低依賴，方便直接放到 GitHub Pages。

## 部署建議

第一階段建議 GitHub Pages：

- 免費。
- 更新方便。
- 推送程式碼後即可重新部署。
- Google TV 使用瀏覽器開啟固定網址即可。

後續可加入：

- `manifest.webmanifest`
- Service Worker
- App icon
- PWA 安裝支援

若 Google TV 瀏覽器支援安裝或加入主畫面，就能進一步做到接近 App 的使用方式。
